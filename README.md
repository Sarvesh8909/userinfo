📌 Info Project (Node.js + Express + MongoDB + EJS)

A simple CRUD application built using Node.js, Express, MongoDB, Mongoose, and EJS.
This project allows you to create and display user information with name, email, and image.

🚀 Features

-Create a new user

-Read and display all users

-Uses MongoDB as database

-EJS templating for frontend views

-Tailwind-style UI design support

-Express REST routes

📦 Dependencies

-Installed dependencies from package.json:

-express

-mongoose

-ejs
